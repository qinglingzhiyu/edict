# 📂 案例 / Examples

真实的端到端使用案例，展示技术部门 (Tech Dept) 处理完整研发需求的全流程。

| # | 案例 | 需求内容 | 涉及岗位 | 复杂度 |
|---|------|---------|----------|--------|
| 1 | [竞品分析](competitive-analysis.md) | "分析 CrewAI vs AutoGen vs LangGraph" | 产品→测试→前端+后端 | ⭐⭐⭐ |
| 2 | [代码审查](code-review.md) | "审查 FastAPI 代码的安全性" | 产品→测试→后端 | ⭐⭐ |

每个案例包含：
- 📜 **原始需求**：业务方指令
- 📋 **产品规划**：PRD 与任务拆解方案
- 🔍 **质量验收**：测试工程师审核意见（含打回/修复记录）
- 💻 **研发执行结果**：前端与后端的产出摘要
- 🚀 **最终上线报告**：运维工程师汇总的完整总结

> 💡 这些案例基于真实运行记录整理，任务 ID 和时间戳已脱敏。
